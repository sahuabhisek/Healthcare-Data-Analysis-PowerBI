# Healthcare-Data-Analysis-PowerBI
Healthcare_Data_Analysis.pbix
Project overview
Is project mein healthcare-related information ko analyze aur visualize karne ke liye Power BI report banayi gayi hai.

Report structure mein teen pages hain:
- PART.1.ADMISSSIONAND.BLOOD .DATASET
- PART.2.DOCTOR.REPORT.INFO
- PART.3.PATIENT_INFO
Report mein healthcare dataset ke fields jaise Hospital, Doctor, Medical Condition, Medication, Blood Type, Gender, Admission Type, Billing Amount aur Admission/Discharge Dates milte hain.
Aap GitHub par project ke objectives is tarah explain kar sakte hain
Patient aur admission analysis
- Admission aur discharge dates se related information explore karna.
- Admission Type aur patient demographics ko analyze karna.
- Medical conditions aur test results ka distribution dekhna.
Hospital aur doctor analysis
- Hospital-related information ko summarize karna.
- Doctor records aur hospital data ko explore karna.
- Medical conditions aur medications ke patterns samajhna.
Billing analysis
- Billing Amount aur average bill se related metrics ko visualize karna.
- Hospital aur medical categories ke beech billing data compare karna.
Identified Power BI features
- KPI Cards
- Slicers
- Column Chart
- 100% Stacked Bar Chart
- 100% Stacked Column Chart
- Funnel Chart
- Pie Chart
- Line Chart
- Ribbon Chart
- Line and Clustered Column Combo Chart
